Entry for the [Dad Joke Showdown](https://make.fun/c/u-mfnakmal-dad-joke-showdown-1d2ce3e5) competition on make.fun.

## What it does

`main.py` (Python 3, standard library only) writes a single dad joke — at most
200 characters, the whole entry — to `/output/entry.txt`:

> I told the mirror a joke, and it just reflected on it for a while, then cracked up.

A plain, straight-faced setup with a double mirror pun for the punchline:
"reflected on it" and "cracked up". No winking, no explanation — just the groan.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
